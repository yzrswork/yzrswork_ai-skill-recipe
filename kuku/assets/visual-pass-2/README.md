# Visual Pass 2

主要ボスのシルエット・表情・構えから改修し、組み込み画像生成で作成した独自イラストを、透過WebPへ変換しています。生成PNGのアルファを保持し、768px以内・モバイル向け容量で保存します。背景は不透明WebP、UI・HP・カーソル・ログ枠・称号は既存のSVG/CSSを維持します。

旧SVGは削除しません。`js/assets.js` が表示用の素材URLと名前を解決し、未登録の素材は旧SVGを使います。ゲームのfact ID・Stage ID・問題生成・保存形式・進行・戦闘計算は変更しません。

`../../visual-pass-2.html` で主要5体の改修前後と、図鑑形式の一覧を比較できます。生成指示は `PROMPTS.json` に記録しています。特定作品・特定キャラクター・特定作家の模倣は指示していません。

| 種類 | 数 | 配信形式 |
|---|---:|---|
| ボス（中ボス・ムゲン・ゼロを含む） | 11 | 透過WebP・768×768 |
| ルートガーディアン | 8 | 透過WebP・768×768 |
| Stage1〜8通常敵 | 24 | 透過WebP・768×768 |
| 深淵通常敵 | 3 | 透過WebP・768×768 |
| 武器・覚醒 | 5 | 透過WebP・768×768 |
| 背景 | 11 | 不透明WebP・1280×853 |

制作モードは内蔵画像生成。各素材を別々の指示で制作し、生成したPNGの原本は作業環境に保持しています。Pillowでサイズ調整・WebPエンコードのみを行い、イラストの描画・合成には使っていません。背景はRGBへ変換し、透過素材はRGBAを保持します。画像のデコード・寸法・アルファ・個別のハッシュ・1MiB未満の容量・旧SVGの存在を追加テストで検証します。

比較ページはレビュー用で、物語や保存へ図鑑解放条件を追加しません。ゲーム内は現在の戦闘に必要な敵・背景・武器だけを読み込み、62点の一括プリロードを行いません。数字・操作・HP・ログは画像へ焼き込まず、既存のHTMLを使います。
