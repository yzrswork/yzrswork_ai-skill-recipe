# 独自ビジュアル素材

背景11点、ボス11点、通常敵27点と深淵3点、守護者8点、武器5点。すべてこの実装用に作成したベクター素材。外部フォント、画像、音源への通信はありません。色に加えて耳・翼・甲羅・工具・冠などで判別します。背景は遠景・中景・地面の3層です。

Visual Pass 2では、全ボス11体・守護者8体・Stage1〜8の通常敵24体・深淵3体・武器5種・背景11枚を `visual-pass-2/` のWebP62点へ切り替えています。元のSVG65点は比較と未登録素材のフォールバックのため保持しています。Stage9の通常敵用SVG3点は現行戦闘では使われないため、WebP化の対象外です。詳細は [Visual Pass 2 README](visual-pass-2/README.md) を参照してください。
