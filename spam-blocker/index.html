    使い方・iPhoneの設定

    GUIDE
    VCFを作った後は？
    1. Safariのダウンロード、または「ファイル」アプリで .vcf を開きます。
    2. 「新規連絡先を作成」で保存します。Quick Blockは「SPAM 番号」、一括登録は「Spam Blocker」という名前です。
    3. iOS 26: 設定 → プライバシーとセキュリティ → 着信拒否した連絡先 →「着信拒否する連絡先を追加」で保存した連絡先を選びます。

    連絡先の詳細に「この発信者を着信拒否」があれば、そこからも操作できます。旧iOSでは設定 → アプリ → 電話（さらに古い版は設定 → 電話）の「着信拒否した連絡先」を確認してください。

    このツールでは、取り込み・着信拒否の完了を検知できません。設定側で対象番号を確認してください。

    Apple: 着信拒否の操作
    ショートカットから番号を渡す

    番号をコピー → ショートカットを起動 → このページで番号を確認し、VCFを作成します。

    1. ショートカットアプリで新規作成し、「クリップボードを取得」を追加。
    2. 「URLエンコード」でクリップボードの文字列をエンコード。
    3. 「URL」に下のアドレスを入力し、末尾にエンコードした結果の変数を挿入。
    4. 「URLを開く」を追加。名前を付け、必要ならホーム画面に追加。
    https://yzrswork.github.io/yzrswork_ai-skill-recipe/spam-blocker/?num=

    既存の ?num=09012345678 も使えます。国際番号の + は %2B にエンコードすると確実です。番号の自動入力だけを行い、VCFはタップ後に作成します。

    共有シートにVCFを渡すショートカットが動かない場合も、URLからSafariを開く経路を使えます。

    一括登録・既存のSPAM連絡先に追加

    1行に1件ずつ入力し「リストへ追加」。同じ国内番号と +81 表記は重複としてまとめます。不正な行があると、その入力全体を追加せず行番号を表示します。

    VCFを開く際に「既存の連絡先に追加」が選べる場合は、以前作った「SPAM」または「Spam Blocker」に追加できます。追加後は連絡先の番号と、設定の着信拒否状態を必ず確認してください。同じ名前の連絡先が自動的に統合されるとは限りません。

    リストからの削除は、この画面の作成対象だけに反映されます。iPhoneの連絡先や着信拒否設定は変更しません。

    SE2 / SE3で履歴の詳細が空白になるとき

    現行版で案内していた回避策です。すべての端末やiOSバージョンで起きるとは限りません。

    履歴の詳細が表示できなくても、番号をコピーできればVCFから連絡先を保存し、設定アプリで着信拒否へ進めます。

    電話アプリだけで試す場合: 履歴の表示メニューで「クラシック」を選択 → 番号の詳細を開く → 空白ならホーム画面へ戻って電話アプリを再表示、またはスクロール。項目が現れたら着信拒否を選択します。改善しなければ設定アプリの経路を使ってください。

    不明な発信者のスクリーニング

    iOSの設定 → アプリ → 電話 →「不明な発信者をスクリーニング」で選択します。提供状況は言語・地域などで異なります。

    通話の理由を尋ねる
    着信音を鳴らす前に、相手に用件を尋ねます。
    消音
    連絡先にない番号の着信を消音にし、留守番電話へ送ります。
    しない
    連絡先にない番号も通常どおり鳴ります。

    迷惑電話を確実に判別する機能ではありません。配達・病院などの正当な電話にも影響します。重要な番号は連絡先に登録してください。ローミング中など、スクリーニングされない場合もあります。

    Apple: 不明な発信者の管理
    貼り付け・ファイルが開けない・ホーム画面

    貼り付けの許可が出たら許可してください。ボタンで貼り付けられない場合は、入力欄を長押しして「ペースト」を選びます。

    VCFはSafariのダウンロード、または「ファイル」アプリから開いてください。ホーム画面やアプリ内ブラウザで取り込めない場合は、このページをSafariで開いて同じ番号を再作成してください。

    ホーム画面に追加する場合は、番号を消したこのページをSafariで開き、共有メニューの「ホーム画面に追加」を選びます。初回の読み込みには通信が必要です。

    番号の確認・プライバシー

    ハイフン・空白・括弧・全角数字、先頭の TEL: / 電話 に対応します。+81と国内表記は同じ番号として扱います。その他の国際番号は + を維持します。桁数と書式を確認するだけで、番号の実在・所有者・迷惑電話かどうかは判定しません。

    番号の自動保存・外部照会・アクセス解析は行いません。旧版の保存リストも自動では読み込みません。VCFは端末にダウンロードされ、取り込んだ連絡先はiPhoneの同期設定に従います。

    URLで渡した番号は最初のページ要求に含まれ、ブラウザ履歴やホスティング側の記録に残る可能性があります。読み込み後にアドレスから除去しますが、既存の記録まで消せるものではありません。これを避ける場合は通常アクセス後に貼り付けてください。
